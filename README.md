# Future-Me-AI
AI-powered Future Self Simulator built with Flask
FutureMe AI

A Flask-based web application that predicts a user's future growth based on study habits, sleep, exercise, and project work.

Features:
- Prediction Engine
- REST API
- Scenario Comparison
- SQLite Database
- Prediction History
- Unit Tests

Routes:
/
 /predict
 /scenario
 /history
 /api/predict
