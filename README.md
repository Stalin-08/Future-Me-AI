# Future-Me-AI

AI-Powered Future Self Simulator built using Flask, SQLite, Bootstrap, and Python.

## Overview

FutureMe AI is a web-based application that analyzes a user's daily habits and predicts future growth potential. The system evaluates study habits, sleep patterns, exercise frequency, and project completion to generate personalized insights about career growth, productivity, and burnout risk.

## Features

* AI-Based Future Prediction Engine
* Career Growth Score Analysis
* Burnout Risk Assessment
* Productivity Index Calculation
* Learning Consistency Evaluation
* Interactive Analytics Dashboard
* Future Scenario Comparison
* SQLite Database Integration
* Prediction History Tracking
* REST API Support
* Responsive Bootstrap User Interface
* Data Visualization with Charts
* Unit Testing Support
* GitHub Collaboration Workflow

## Technologies Used

* Python
* Flask
* SQLite
* SQLAlchemy
* Bootstrap 5
* HTML5
* CSS3
* Chart.js
* Git & GitHub

## Routes

* `/` → Home Page
* `/predict` → Generate Future Prediction
* `/dashboard` → Analytics Dashboard
* `/scenario-page` → Scenario Comparison Interface
* `/scenario` → Scenario Prediction API
* `/history` → Prediction History
* `/api/predict` → REST API Endpoint

## Prediction Parameters

* Study Hours
* Sleep Hours
* Exercise Days
* Completed Projects

## Generated Metrics

* Career Score
* Burnout Risk
* Productivity Index
* Learning Consistency
* Future Status
* AI Recommendations

## Database

The application uses SQLite to store:

* User Inputs
* Prediction Results
* Career Scores
* Burnout Metrics
* Future Status Records

## Project Goal

To help users understand how their current habits can influence their future success and encourage better decision-making through AI-powered predictions and analytics.
